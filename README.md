## 🚀 Getting Started: Ascend to the Throne

Acquiring this tool is the first step toward a more efficient reign. We have removed all barriers to entry.

1.  **Acquire the Archive:** Obtain the latest version of the package from the official secure channel. The delivery is seamless and does not require a complex setup ritual.
2.  **Invoke the Interface:** Place the files in the directory that suits your leadership style. The tool is designed to run alongside your game client without interfering with the core processes.
3.  **Synchronize your Session:** Launch the game and let the tool detect your profile. It will automatically read the current state of your colony and offer its services.
4.  **Issue Your First Decree:** Use the main dashboard to view your initial metrics. Try turning on the "Resource Flow Optimizer" to see an immediate difference in your supply lines.

**System Requirements:**
- **Operating System:** Windows 10/11, macOS 12+, or a modern Linux distribution.
- **Memory:** 8 GB RAM (16 GB recommended for large colonies).
- **Storage:** 200 MB of available space.
- **Display:** 1280x720 minimum resolution.

## 🛠️ Advanced Configuration & Customization

This tool is not a one-size-fits-all crown. It is a modifiable framework that respects the unique flair of your reign.

**Policy Settings:** Adjust the "Iron Fist" slider to determine how aggressively the tool reallocates resources. A low setting is gentle and advisory; a high setting is assertive and proactive.

**Script Integration:** Advanced users can write "Decree Scripts"—simple text files that define complex sequences of commands. For example, you can have a script that automatically executes a series of trade agreements at the start of each game month.

## 🛡️ Security and Integrity

In a world where internal betrayal is a constant threat, trust is paramount. **Pax-Autocratica-Tool** operates entirely locally on your machine. There are no telemetry or data-collection protocols. We believe that your empire's data is your own. The tool reads the game's memory only to understand the current state and writes no modifications that could corrupt your save files. It is the loyal bodyguard that watches your back without ever asking for a place at the table.
